# Business Intelligence Case Study: Koro 🛒
**Transforming Raw Transactional Data into Actionable Growth Insights**

## 📌 Project Context
This project was developed as a professional technical assessment to evaluate the customer lifecycle and marketing efficiency of **Koro**. The analysis bridges the gap between raw backend database records and executive-level KPIs.

## 🚀 Key Business Questions Addressed
- **Growth:** What is the daily velocity of new customer acquisition?
- **Retention:** What percentage of users return for a second or third order?
- **Marketing:** Which channels (Social, Organic, Referral) yield the highest quality customers?
- **Strategy:** Which product categories are driving international expansion in specific countries?

## 🛠️ Technical Implementation
### 1. SQL Analytics (The Engine)
[cite_start]Developed complex SQL queries to extract performance metrics from relational data:
- **Daily/Monthly Active Users (DAU/MAU):** Tracking engagement over time.
- **Repeat Order Analysis:** Calculating the time-to-second-purchase to identify the "loyalty threshold."
- **Channel Attribution:** Segmenting customer lifetime value (LTV) by acquisition source.

### 2. Python Visualizations (The Story)
[cite_start]Utilized **Pandas**, **Matplotlib**, and **Seaborn** to create executive dashboards:
- **Customer Breakdown:** Visualizing the mix between "One-Time Buyers" and "Loyalists."
- **Category Deep-Dives:** Identifying "Star Products" in different geographic markets.
